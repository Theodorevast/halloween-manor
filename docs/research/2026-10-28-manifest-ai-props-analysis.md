# 访客反馈、手电照出鬼魂、主动显形、新物件：分析（2026-10-28）

用户这次提的四件事，先分析、不动手，具体做法回来再一起定：

1. 访客（AI）的反馈要更好
2. 被访客的手电照到时，鬼魂应该显形
3. 做一个主动显形吓人的功能（以后会改鬼魂的模型，还会加一个联名模型）
4. 给一些物件加吓人的功能

这四件事是连在一起的：手电照到会显形、主动显形，都要访客有像样的反应才成立；新物件也一样。下面先说现在是什么样，再分条分析，最后是排期建议和要问用户的问题。

---

## 0. 现在是什么样（代码里查到的）

- **访客怎么看**：视野就是手电光锥，半角 30°、7 米远，再加格子视线（`sim/perception.ts`）。听见按距离算，隔墙打折
- **访客的状态**：进门 → 闲逛（走到随机点、左右照）→ 警觉（听到声音走过去查看）→ 受惊（僵住 0.8 秒、跳一下、够多就尖叫）→ 恐惧值满了就逃跑（`sim/npc.ts`）。另外还有：被蓄势中的惊吓物件「定住」盯着看；听到别人尖叫会被传染；同一种物件反复吓会习惯（减半，15 秒恢复）
- **鬼魂和访客的关系**：上一轮定下的规矩是**访客看不见鬼魂**。鬼魂在身后 1.5 米内会让人发毛（恐惧值慢慢涨、走慢、偶尔回头张望，但什么也看不见），0.8 米内停 2 秒是一次「后颈一凉」（`config/visitors.ts` 的 `GHOST`）
- **鬼魂的画法**：不受光照、加法混合的半透明人形，材质不挑网格，换模型只要换 `buildGhostGeometry`（`view/ghost.ts`）。手电的光对它**没有任何作用**：光锥扫过去它照样是那团淡淡的雾，这就是用户说的「被照到了也不显形」
- **物件**：两种。引诱（八音盒、厨房门：发出声音把人引过来）和惊吓（台灯、摇椅、肖像、镜子：要被看见，有蓄势和落下的时刻）。门厅和走廊一个物件都没有
- **访客能用来「表达」的东西**：没有脸，所以只有身体、手电和声音。动作现在只有 4 个（待机、走、跑、受惊），声音有尖叫、倒吸气、发抖的呼吸、后颈一凉的那一口气，没有说话。Tripo 还能加的预设动作里，对得上的有：`afraid`、`frightened`、`scared_02`、`look_around`、`flee_01`、`flee_02`、`turn`、`cry`、`fall`（每个访客每个动作 10 积分，四套就是 40）

## 1. 访客的反馈要更好

「反馈不够好」可能是几种不同的问题，**要先问用户指的是哪一种**（见最后的问题 1）。按我对现状的判断，排了个序：

### 1a. 原因和结果对不上，看不出「他注意到了」（最可能）
现在访客听到声音，是直接转身走过去；被吓到，是直接跳。中间没有「察觉」这一拍。真人的顺序是：**停下 → 手电先转过去 → 愣一下 → 再决定**（走近看、后退、跑）。
- 做法：听到、瞥见、发毛的时候先加一段短的「察觉」（0.3–0.6 秒，停步、手电先转、身体后转），再进入后面的行为。只改模拟和表现层，不用新资源
- 手电就是访客的「脸」：平静时稳、搜索时慢扫、紧张时抖（已有）、被吓时猛地甩过去（已有）、**吓完以后在那个地方多停一会儿**（现在马上就移开了）、怕到极点时手电往下垂

### 1b. 每个人都一样，像机器
三种性格现在只有恐惧倍率不同，走路、照手电都一样。
- 胆小的：贴着墙走、步子小、常回头、听到一点声音就停
- 胆大（skeptic）的：走在中间、手电照得稳，听到声音会**主动走近查看**，被吓到以后可能还要再看一眼才跑
- 一起行动：怕了会往别人身边靠，有人逃跑时旁边的人也会紧张（现在只有尖叫会传染）

### 1c. 没有声音上的反馈
现在只有尖叫和倒吸气。可以加：
- 不用说话的：紧张时听得见的喘气（3D 定位，凑近才听见）、小声的呜咽、手电被吓到时的「啪嗒」开关声
- 要说话的（「Hello?」「Who's there?」「Nope.」）：程序化合成做不出像样的人声。可以用公司素材中台网页上的 AI 语音生成英文短句，那个功能命令行没有，要用户在网页上操作。吉祥物没有嘴，说话也可能显得出戏，**要问用户**

### 1d. 动作太少
4 个动作撑不起这么多状态。建议加：`look_around`（警觉、查看时）、`afraid` 或 `frightened`（紧张时站着的样子）、`flee_01`（逃跑）、`scared_02`（第二种受惊，免得每次都一样）。四套一共约 160 积分。
- 流水线一次 retarget 最多 5 个动作，现在已经用了 4 个，要改成分两次请求，再在 Blender 精修里把动作并到一个 GLB 里（小改动）

**我的建议**：先做 1a（察觉那一拍、手电行为）和 1d（加动作），这两项最能让人觉得「他注意到我了」；1b 挑性格差异最明显的两三条做；1c 先只做不说话的声音。

**用户的回答（2026-10-28）**：1a–1d 四项都要。另外补充了一条：「有时候都不知道在什么范围内可以吓到他，比如在面前可以吓到，在背后，有声音，但是它没有被吓到，也不会转头做反馈」。

### 1e. 不知道在什么范围内能吓到他（用户补充）
查了一下，这是两个原因叠在一起：
- **鬼魂的声音访客听不见**：穿墙的「呼」、飘动的冷风只放给玩家听（`audio/ghost.ts`），模拟里访客的听觉只管物件的引诱声和别人的尖叫。玩家听见了、访客没有，两边对不上
- **背后的发毛反应太少、太随机**：要发毛到一定程度（`GHOST.glanceMin`），满强度时也只是平均每 3 秒、至少隔 2.5 秒才有一次回头（`glanceEvery`、`glanceGap`）；其余时候只是恐惧值悄悄涨，画面上看不出来

要做的：
- **靠近就有反应，而且立刻**：鬼魂进入发毛范围后半秒内，访客停一下、回头照一下；接着停留就递进（发抖 → 后退、手电一直照着背后 → 后颈一凉）。不再靠随机
- **鬼魂的声音要么访客也听得见，要么做成一个专门的「低语」**：低语是在鬼魂的位置发出的引诱声，听见的人转头照过来、走过来查看。这样「在背后弄出声音 → 他回头」就是一定成立的
- **告诉玩家「手电光就是他的眼睛」**：站进某个访客的光锥时给一点提示，比如准星变一下、鬼魂轮廓上一圈很淡的光边，意思是他现在看得见你（现身能吓到他）。开场的操作提示里也加一句
- 这三条也是第 2、3 节的基础：被照到会愣住、背后的低语会让人回头，主动显形才有时机可抓

## 2. 被手电照到时显形

这是个很好的点子，和上一轮的定案不冲突，反而补全了它：**黑暗里访客看不见鬼魂，被光照到就看得见**。这也是很多鬼故事里的画面：手电扫过去，光里有个人影。

### 画面（怎么「显」）
- 鬼魂的着色器里加上「在不在某支手电的光锥里」：屋里最多 4 支手电，每支传位置、方向、角度、距离进去，再由 CPU 判断这支手电和鬼魂之间有没有墙。在光锥里的部分变浓、轮廓变清楚、带一点手电的暖色，光锥外面还是原来的冷雾
- 按「效果要克制、写实，不要游戏感」的口味（之前的反馈）：不发光、不闪，就是光里多了一个人影。可选加一项：**鬼魂在光里时往墙上投一个影子**。很吓人，代价是多画一次阴影图，而且阴影只能是实的
- 和模型无关：换成联名模型也照样能用（显形是材质的事，不是模型的事）

### 玩法（被照到会怎样）——要问用户
- A. **被照到就会被看见、被吓到**（被动）：照到的时间越长、离得越近，涨的越多；胆大的会走过来照着看，胆小的直接退。好处是直观；坏处是鬼魂飘到人面前就能吓人，附身物件就没那么重要了，要靠习惯化和冷却压住
- B. **照到只是「显」，不会吓人**：光里能看到人影（画面效果），访客「愣一下」（1a 的察觉，恐惧值涨一点点），真正的惊吓要主动显形（第 3 节）。平衡最稳，玩家要判断时机
- C. 介于两者之间：照到 = 访客瞥见、愣住、恐惧值涨一小截（相当于后颈一凉，12 左右），一个人短时间内只算一次；想吓大的还是要主动显形

**我的建议是 C**：被照到会有反应（用户要的就是这个），但不至于变成「飘到人面前就赢」；还能和主动显形连起来——被照到、对方愣住盯着你看的那一刻，正好是主动显形的最佳时机。

**用户选了 B（2026-10-28）：只显形、不吓人。** 光里能看到人影（画面效果），访客只是略微一顿（察觉那一拍，不涨或几乎不涨恐惧值）；吓人全靠主动现身和物件。平衡最稳，「飘到人面前就能吓跑人」的问题不存在。被照到时访客那一顿，正好给主动现身一个看得见的时机。

## 3. 主动显形吓人

### 三种做法
- A. **点一下就显**：0.5–1 秒的现身，看得见的人都被吓一大跳，冷却 20 秒左右。最简单，手感最直接
- B. **按住蓄力、松开现身**：蓄力时附近的灯闪、手电抖、地上结霜、有低低的声音。这是给访客的「预兆」：他们会停下来四处照，所以现身时更容易被看见。蓄力越久越吓人，冷却也越长
- C. **开关式、耗能量**：现身期间看到你的人持续被吓，能量用完就得躲起来回复。最有深度，但要加资源条，和沙盒、不加 UI 的路线不太搭

**我的建议是 B 的简化版**：固定的短蓄力（约 0.6 秒，和物件的蓄势一样），现身约 1.5 秒，冷却约 15–20 秒。理由：
- 物件已经有「蓄势 → 落下」这一套（`hitAt`），访客会被蓄势定住，代码和手感都能直接复用
- 能和现有的玩法串起来：贴在身后让他发毛 → 他回头张望 → 这时现身，正好被看见。或者被手电照到、他愣住盯着你 → 现身
- 吓多少：按离得多近、在不在光锥正中、是不是在光里算，基础值和肖像差不多（30 左右），同一个人重复会习惯
- 按键：右键或 F（左键已经是附身）。触屏的娃娃屋模式没有鬼魂本体，不做

**用户选了「短蓄力再现身」（2026-10-28）**：按一下，蓄力约 0.6 秒（预兆：附近的灯闪、手电抖、地上结霜），现身约 1.5 秒，看得见的人被吓；冷却 15–20 秒。

### 画面和声音
克制写实：人影一下子变浓、变清楚，周围的灯暗一下，冷雾往外涌，镜头不推近（上一轮做减法时去掉了）。声音沿用现有的风格：低沉的气声、反向的渐强、最后一下低频冲击，不用大调、不用上行音阶。

### 换模型、联名模型
- 鬼魂现在是程序化的静态网格，靠顶点飘动。换成别的模型只要换一个函数，材质不用动
- 如果联名模型要有动作（飘着待机、现身时扑过来），就要绑骨。Tripo 的人形绑骨对没有腿的鬼不一定合适，要试；也可以不绑骨，继续用飘动
- **要问用户**：联名模型是替换现在的鬼、当成可选外观、只在现身时出现（「真身」），还是做成一个特别的访客？模型从哪来（Tripo 生成，还是对方给）？什么时候能拿到？公开使用有没有授权？

**用户的回答（2026-10-28）**：「是准备做吉祥物的联名装扮，然后主角鬼魂我也准备改一下。」所以：
- **联名 = 吉祥物访客的一套联名服装**：走现有的访客流水线（`scripts/tripo/visitors.json` 加一个 variant → 换装图 → 中台修图 → 四视图 → P2 → 绑骨 → 动作 → Blender 精修），和现在四套一起轮流出场。要准备：联名对象的参考图、授权
- **主角鬼魂用户自己改模型**：显形（手电照出人影）和现身做在材质上，不绑在模型上。新模型是静态网格还是带骨骼和动作的 GLB 都能套用；带动作的话，现身那 1.5 秒可以配一个扑过来的动作

## 4. 给物件加吓人功能

### 现在缺的
- 门厅和走廊没有物件，新访客要走进房间才会被吓（之前布局调整时的取舍）
- 吓人的方式只有「听见」和「看见」两种

### 可以直接用现有家具改的（模型已有，要把会动的那块拆出来，再加动画和声音）
| 物件 | 房间 | 怎么吓 | 种类 |
|---|---|---|---|
| 衣柜 | 卧室 | 门慢慢自己开，里面的外套晃了一下 | 惊吓 |
| 衣帽架 | 门厅 | 外套滑落、架子倒下 | 惊吓（门厅终于有东西了） |
| 书架 | 书房 | 书一本接一本滑出来掉在地上 | 引诱 + 惊吓 |
| 壁炉 | 客厅 | 冷炉膛里突然窜起一团苍白的火，马上又灭 | 惊吓（会照亮房间） |
| 浴缸龙头 | 浴室 | 水龙头自己开了，先滴后流 | 引诱 |
| 炉灶上的锅 | 厨房 | 锅盖咔哒咔哒地跳 | 引诱 |
| 书桌上的蜡烛 | 书房 | 一根接一根灭掉 | 惊吓 + 变暗 |
| 床 | 卧室 | 被子慢慢鼓起来，像有人躺在下面 | 惊吓（很瘆人，也克制） |

### 新的吓人方式（不是新物件，是新种类）——和第三人称鬼魂特别搭
- **附身访客的手电**：贴近一个人，让他的手电闪几下、灭掉几秒。黑暗里他会慌（恐惧值涨、往人多的地方跑），**手电再亮起来的时候你就在光里**，配合第 2、3 节，这是最强的一套连招。我认为这是最值得做的一项
- **熄灯**：一间屋的灯灭几秒，屋里的人只剩手电，配合「光里才看得见鬼」
- **挡路**：门自己关上、椅子滑到路中间。访客要绕路，可以把人往别的物件那边赶
- **机关**：先附身、设好，有人走过时才触发（比如衣柜在有人经过时猛地打开）。玩家可以设好就走

### 每加一个物件要做的
程序化模型（或用 Tripo 生成）、惊吓动画、声音（程序化合成，守住声音规矩）、模拟参数（范围、恐惧值、冷却、蓄势时刻）、物件溶解、预编译、平衡测试。熟练的话每个 2–4 小时。要注意：**新加的灯要一开始就放进场景**（灯的数量一变，所有材质都要重编，会卡）。

**我的建议**：上线前只加两样：门厅的衣帽架（模型现成，填上门厅的空），和「附身手电」这个新种类。走廊也该有个东西（比如尽头一座落地钟），但要新建模型，放到上线后；其余的也上线后再说。

**用户的回答（2026-10-28）**：选了「其他房间的家具」，另外「可以考虑机关」。还要求「有些效果要做得恐怖，比如 2D 和 three.js 或者其他技术，我们得细节优化，一个一个看」，让我去搜比较恐怖的画面和镜头语言（调研交给后台助手，结果写进 `docs/research/2026-10-28-horror-visual-language.md`）。附身手电、门厅衣帽架没有选，先不做。

## 5. 几件事放在一起看

- **平衡**：现在的平衡是机器人测出来的（`tests/balance.test.ts`），之前定的不变量是「只靠鬼魂吓不跑胆大的人」。加了显形以后，这一条要不要保留，要定。机器人也要学会显形、附身手电
  - **用户的回答（2026-10-28）**：现身「可以促使访客改变方向」，确认后是「赶人，但也能吓跑」：看到现身的人会后退、转向、一段时间内绕开现身的地方，玩家可以拿它把人赶到物件前面；用得好（时机对、离得近、在光里）也能单独把胆大的吓跑。所以「只靠鬼魂吓不跑胆大的」这条不变量取消，改成「现身能吓跑人，但比配合物件慢」，机器人测试按这个改
- **性能**：显形只是鬼魂着色器里多算 4 支手电，可以忽略；往墙上投影子要多画一次阴影图；新物件的灯要提前放好
- **和上一轮反馈的关系**：上一轮说「访客动作太夸张、特效太杂」，这次说「反馈要更好」。两者不矛盾：要的是**看得懂**，不是**更夸张**。所以上面的建议都是加「察觉那一拍」、加不同的动作、加克制的声音，而不是跳得更高、特效更多

## 7. 回来要问用户的问题（一次问一个）

1. 访客反馈「不够好」主要指哪种：看不出他注意到了（1a）／每个人都一样（1b）／没有声音（1c）／动作太少（1d）？
2. 被手电照到：A 被照到就被吓／B 只显形不吓／C 愣一下、涨一小截（我推荐 C）？
3. 主动显形：A 点一下／B 按住蓄力／C 开关耗能量（我推荐 B 的简化版）？
4. 联名模型：替换现在的鬼／可选外观／现身时的真身／特别的访客？模型从哪来、什么时候到、有没有授权？
5. 新物件：上面的表里想要哪几个？「附身手电」要不要？
6. 「只靠鬼魂吓不跑胆大的人」这条平衡规则还要不要？
7. 上线前一定要有的是哪些，哪些可以放到上线后？
