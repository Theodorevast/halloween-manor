## 1. 范围和砍掉的顺序

| 档 | 内容 |
|---|---|
| **必须** | 访客察觉那一拍、发毛立刻有反应、鬼魂穿墙声访客听得见、尖叫只留给吓破胆的时候、性格差异两条、4 个新动作、紧张时喘气和吓坏时呜咽；手电照出鬼魂；主动现身（模拟、画面、声音）；床；机关 |
| **有空就做** | 鬼魂被手电照到时在墙上的影子（L2）、衣柜（先 A 版再 B 版）、性格的其余细节、灯闪节奏表套到现有台灯上 |
| **上线后** | 壁炉的影子、蜡烛、书架、龙头、锅盖、「房子越来越不对劲」、低语、联名装扮（等素材和授权）、新鬼魂模型（等用户的模型） |

时间不够时，从「有空就做」倒着砍。「必须」里的察觉那一拍、手电照出鬼魂、主动现身不砍。

**默认项**（用户在看样时可以否决）：现身时鬼魂不动、头慢慢抬起，不扑过来；被吓到以僵住为主，尖叫只留给吓破胆的时候；按住左键约 0.5 秒设机关；准星外面一圈很淡的现身冷却环；不做慢推近。

**一直守住的口味**：克制、写实，不要游戏感（不发光、不描边、不全屏闪图、不加 UI 闪烁）；声音不用大调、和弦进行、上行音阶、「叮」；吉祥物不见血。灯闪每秒不超过 3 次（WCAG 2.3.1）。

## 2. 访客反馈（子项目 A）

### 2.1 察觉那一拍（notice）
- **触发**：听到声音（引诱、别人的尖叫、鬼魂穿墙声）、手电照到鬼魂、开始发毛、现身的蓄力（附近灯闪）
- **过程**：减速停下（`MOTION.decel`，不急刹）→ 手电先转向来源（转向速度是平常的 2 倍）→ 身体跟着转（平常的速度）→ 盯着看 `NOTICE.hold`（0.5–1 秒，随机）→ 按来源和性格决定下一步：
  - 声音：走过去查看（现有的警觉）。胆大的走得更近
  - 手电照到鬼魂：不涨恐惧值，看完继续原来的事（已定：只显形，不吓人）
  - 发毛：见 2.2
  - 现身蓄力：一直盯着蓄力的地方，直到落下（和物件蓄势的「定住」同一个机制）
- 受惊（startled）、逃跑中不触发；察觉中又来一个来源时，优先级高的或一样高的就转向新来源、重新计时（优先级：现身 > 声音 > 手电照到鬼魂 > 发毛）
- 模拟发 `notice` 事件；画面靠模拟给的 `lookDir` 和 `heading` 就能表现，不用另写

### 2.2 发毛立刻有反应
- 鬼魂进入发毛范围（`GHOST.radius`）后的 **0.5 秒内**，访客停一下、回头照一下（就是一次 2.1 的察觉，来源是鬼魂此刻的位置，手电照过去：如果照到了鬼魂，2.1 的「手电照到」也成立）
- 每次「进入范围」只触发一次；一直贴着就按程度递进：发抖（已有）→ 后退半步，同时手电一直照着背后 → 后颈一凉（已有）
- 去掉原来的随机回头（`glanceEvery`），改成上面这套确定的反应

### 2.3 鬼魂穿墙声访客听得见
- 鬼魂穿墙时（`GhostState.inWall` 从假变真），`GHOST.hearWall`（3 米）内的访客听得见，触发 2.1（来源是穿墙的位置），恐惧值涨一点点（2）
- 鬼魂的其余声音（飘动的冷风）访客听不见

### 2.4 尖叫只留给吓破胆的时候
- 一次涨得多才尖叫：`FEAR.screamAt` 从 15 提到 25；恐惧值到 `FEAR.dread`（80）以后，再被吓一次也尖叫
- 其余的惊吓是僵住加倒吸一口气（已有的 gasp）
- 尖叫会传染，所以这一条会改变平衡，要跟着调

### 2.5 性格差异（必须两条，其余有空就做）
- **胆大的（skeptic）**：查看声源时走到 0.8 米（平常 1.5）；被惊吓类物件吓过以后，有一半的几率会再照一眼那个物件（1 秒）才走
- **胆小的（scaredy-cat）**：察觉时盯得更久（`NOTICE.hold` × 1.5）；发毛的范围 × 1.2（更早有反应）
- 有空再做：胆小的贴墙走、步子小；怕了往别人身边靠

### 2.6 新动作
- Tripo 预设：`look_around`（察觉、查看时）、`afraid`（紧张时站着）、`flee_01`（逃跑）、`scared_02`（第二种受惊，和 `scared_01` 轮流用）
- 四套各 4 个，共 160 积分（用户已同意）
- 流水线：一次 retarget 最多 5 个动作，所以分两批（第一批是现有的 4 个，第二批是这 4 个）。Blender 精修把第二批 GLB 的动作并到第一批的骨架上，导出一个 GLB
- `CharacterSpec.clips` 加 `look`、`afraid`、`flee`、`scared2`，没有的写 null（占位狐狸、备用小人照旧）

### 2.7 声音
- **紧张时喘气**：恐惧值到 `FEAR.nervous` 以后，每个访客一路很轻、3D 定位的喘气（现有的 shiver 呼吸合成，循环、按恐惧值加快）。凑近才听得见
- **吓坏时呜咽**：恐惧值到 `FEAR.dread` 以后偶尔一声（共振峰合成，短、低，不像哭）

## 3. 手电照出鬼魂和主动现身（子项目 B）

### 3.1 手电照出鬼魂（G1）
- 鬼魂的着色器里，每个片元判断在不在某支手电的光锥里（最多 4 支：位置、方向、半角、距离、强度），再乘上「这支手电和鬼魂之间有没有墙」（CPU 用格子视线算，每帧每支一次）
- 在光锥里：变浓（不透明度 × 约 3）、轮廓变清楚（soft 区间收窄）、带一点手电的暖色；越靠光锥中心越明显。光锥外还是原来的冷雾
- **模拟**：访客的手电照到鬼魂（`canSee` 到鬼魂的位置）→ `reveal` 事件（on / off）和 2.1 的察觉。恐惧值不涨
- **给玩家的提示**：被任何一支手电照着时，一层很低、很轻的压力声淡入（约 −30 dB），离开淡出。不做描边、发光、UI
- **有空就做**：鬼魂被照到时往身后的墙上投影子（L2，`maskShadowNode`，只进手电的阴影图）

### 3.2 主动现身
**操作**：右键或 F。冷却 18 秒；准星外面一圈很淡的环表示冷却。娃娃屋（触屏）模式没有。

**时间轴**（模拟和画面、声音用同一套时刻）：
| 时刻 | 模拟 | 画面 | 声音 |
|---|---|---|---|
| 0.00–0.60 蓄力 | 5 米内的访客察觉（2.1），盯着鬼魂的位置 | 5 米内的灯像坏灯泡一样暗两三下（压到 30–50%，越暗越偏红，不全灭，不白闪，L1）；访客的手电跟着暗、抖；脚下的霜往外长到半径约 1.2 米（S1） | 环境声在 0.5 秒里压低（A1）；一个小二度的低持续音淡入（A2）；灯每暗一下一声很轻的咔哒；0.4 秒以后几乎全静 |
| 0.60 落下 | 结算谁被吓到（下面） | 附近的灯和手电一起暗 80–120 毫秒，亮回来时鬼魂已经「实」了（G2：暗、挡光，被照到的那面看得出褶） | 低频冲击（A3）+ 很近的一口冷气（A6）。不尖叫、不放音乐 |
| 0.60–2.10 停留 | 看得见鬼魂的人持续「定住」 | 几乎不动（平时的飘动停下），头在 1.5 秒里慢慢抬起或偏 5–10°，每秒只更新 10 次（G3）；冷雾从下摆往下淌；附近的灯保持在 40% 左右 | 低持续音保持 |
| 2.10 收 | 进入冷却 | 再暗一下 60–100 毫秒，亮回来时鬼魂回到平时的雾（G4）；霜在 3–5 秒里化掉 | 环境声 1–2 秒后才回来 |

**谁被吓到、吓多少**：落下那一刻，看得见鬼魂（`canSee`：光锥 + 视线 + `MANIFEST.range` 6 米）的每个人：
- 恐惧值 = `MANIFEST.fear`（30）× 距离系数（1 米内 1.3，6 米处 0.6，中间线性）× 正中系数（在光锥正中 1.2，边上 0.9）× 在光里（被这个人的手电照着）1.25 × 性格倍率 × 习惯化（按 'manifest' 这一种算）
- 被吓到以后：照常受惊（僵住、够多就尖叫、满了就逃跑），然后**转身后退**：离开鬼魂至少 1.5 米，接着在 `MANIFEST.avoidTime`（20 秒）内绕开以现身地点为中心、`MANIFEST.avoidRadius`（2.5 米）的圆（寻路时把这块当成不能走，除非整条路都绕不开），用来「赶人」
- 用得好也能把胆大的吓跑（用户已定）；平衡的新不变量：只靠现身能吓跑胆大的，但比配合物件慢（机器人测）

**不做**：发光、变大、扑过来、说话、全屏特效、推近镜头。

**以后换模型**：显形、变实、降帧、借光出入都做在材质和时间上，换成用户的新鬼魂模型也能用。新模型是静态网格还是带骨骼的 GLB 都要接得住（`GHOST_MODEL` 配置：url、有没有动作）；有动作的话，停留那 1.5 秒播它的现身动作（照样降到每秒 10 帧）。

## 4. 床和机关（子项目 C）

### 4.1 床：被子下面有人（S4）
- 卧室里现有的床（`furniture.ts`）把被子拆出来，成为新的可附身物件 `bed`（惊吓类）；床架留在家具里
- 时间轴：0–1.2 秒鼓起一个人形（膝、躯干、头三个鼓包依次升起）→ 1.2–2.2 秒像睡着的人一样慢慢起伏（周期约 3 秒），听得见很低的、被布闷住的呼吸 → 2.2–2.6 秒头那块转向访客、呼吸停 → **2.6 落下**：一下子塌平（约 0.12 秒），被子「噗」地落回、扬起一点灰，低频冲击 → 留下一个人形凹陷，5 秒里慢慢回平
- 模拟：`bed: { kind: 'sight', range: 5, fear: 26, cooldown: 14, active: 3.2, hitAt: 2.6, broken: 0 }`（数值按机器人测调）；蓄势里访客被「定住」（现有机制），所以落下前会一直看着
- 被子网格细分到约 40×60，顶点位移做鼓包；溶解、预编译和其余物件一样

### 4.2 机关
- **设下**：对着物件按住左键约 0.5 秒（点一下还是立刻附身）。设下的物件只有玩家看得见一层薄霜（S1 的小号），物件上方的眼睛标记换成空心
- **触发**（按物件分两种）：
  - 背后型（摇椅、床、衣柜）：访客走过、物件在他背后 1.5–3 米时开始蓄势 → 蓄势的声音让他察觉（2.1）、回头 → 落下。用现有的「听见」和「看见」两条规则
  - 迎面型（肖像、镜子、台灯）：访客的手电照到物件时触发
  - 引诱类（八音盒、厨房门）：有人进入听得见的范围就响
- **等时机**：进入范围后最多等 1.5 秒，挑他离得最近、或手电正好扫到的那一刻；等不到，就在他离开范围之前触发
- **限制**：同时最多 2 个；设下 60 秒还没触发就自动解除；恐惧值 × 0.9，冷却照常
- 模拟：`ScareObjectState.armed`（剩余秒数），`World.arm(id)`，`trap` 事件（armed / sprung / expired）

### 4.3 衣柜（有空就做）
按调研 3.3：门自己开一条缝（只有外套），停住，落下时随机出 A「被从里面拉上」或 B「手电一抬，柜顶蹲着一个剪影」。B 版要给手电加「照向高度」。先做 A。

## 5. 架构和接口（并行开发前先定好）

### 模拟（`src/sim/`，纯 TS）
- `types.ts`
  - 事件：`{ type: 'notice'; npc; kind: 'sound' | 'ghost' | 'chill' | 'manifest'; src: Vec2 }`、`{ type: 'reveal'; npc; on: boolean }`、`{ type: 'manifest'; phase: 'windup' | 'drop' | 'end'; pos: Vec2; scared: number[] }`、`{ type: 'trap'; object; phase: 'armed' | 'sprung' | 'expired' }`
  - `WorldState.manifest: { phase: 'idle' | 'windup' | 'hold' | 'cooldown'; t: number; cooldown: number; pos: Vec2 | null }`
  - `WorldState.avoid: { pos: Vec2; r: number; until: number }[]`
  - `ScareObjectState.armed: number`
  - `NpcState.notice: { kind; src: Vec2; t: number } | null`（画面、调试用）
  - `World.manifest(): boolean`、`World.arm(id: string): boolean`；`World.setGhost` 加上 `inWall`
  - `ScareType` 加 `'bed'`（有空再加 `'wardrobe'`）
- `config/visitors.ts`：`NOTICE`、`MANIFEST`、`TRAP`、`PERSONALITY_TRAITS`，`GHOST.hearWall`，`FEAR.screamAt` 改 25
- `config/scares.ts`：`bed`
- 寻路：`avoid` 圆里的格子代价很高（不是完全不能走）

### 画面（`src/view/`）
- `torches.ts`（新，很小）：手电的共享登记表。`characters.ts` 每帧写（位置、方向、半角、距离、强度），`ghost.ts` 读
- `ghost.ts`：手电照出（G1，uniform 数组 4 个）、变实（G2，`solid` 0..1）、降帧（G3）、借光出入（G4，和灯闪同步）、墙上的影子（L2，有空就做）；新模型的接口 `GHOST_MODEL`
- `lightfx.ts`（新）：附近灯的闪烁和压暗（L1：Quake 式节奏表 + 越暗越偏红），按「离某点多远」挑灯；手电强度乘一个系数（`flashlight.ts` 加接口）。现身和机关、台灯共用
- `frost.ts`（新）：地上的霜（S1），现身用大号，机关提示用小号
- `props/bed.ts`（新）；`furniture.ts` 的床不再画被子
- `characters.ts`：新动作的混合（察觉 → look，紧张站着 → afraid，逃跑 → flee，受惊轮流 scared / scared2）
- `overlays.ts`：机关的空心眼睛标记

### 操控（`src/engine/`）
- `ghostRig.ts`：右键和 F → `onManifest`；准星的冷却环（`setGhostUi`）
- `picking.ts`：第三人称下按住约 0.5 秒 → `onArm(id)`；点一下照旧 `onPick`
- `main.ts`：接线

### 声音（`src/audio/`）
- 现身（A1 压低、A2 小二度低持续音、灯的咔哒、A3 低频冲击、A6 冷气、环境声晚回来）；被照到时的低压声；访客的喘气、呜咽；床（布料、闷住的呼吸、「噗」）；机关设下时极轻的冰裂声（只有玩家听得见）

### 流水线（`scripts/tripo/`、`scripts/blender/`）
- 动作分两批 retarget，Blender 精修合并动作；四套重导出

## 6. 测试
- 模拟单测：察觉那一拍的时序；进入发毛范围 0.5 秒内回头；穿墙声 3 米内听得见；手电照到鬼魂不涨恐惧值；现身只吓看得见的人、吓完后退并绕开 20 秒；机关的背后型触发、60 秒解除、最多 2 个；尖叫阈值
- 平衡（机器人）：新加「会现身」的机器人；不变量改成「只靠现身能吓跑胆大的，但比配合物件慢」；现有的几条按新的尖叫阈值重测
- 冒烟测试：右键、F 现身有事件；按住设机关；床在场（物件数 7 → 8，准星对准每个物件那一项跟着改）
- 性能：四个访客满载 High、Low 仍然 60 fps；冷启动不超过 4.5 秒
- 每个效果一个预览页（`dev/` 下），和用户一个一个看：手电照出（含墙上的影子）→ 现身 → 灯闪 → 床 → 机关的手感 → 衣柜
